# Unit 1 — Lesson-Flow Map (Mission Book ⇄ Teacher Deck ⇄ Flight Log)

Verifies the three artifacts run the **same flight** for every standard (US.01–US.07)
and that each write-point is signposted on the slides. Slide numbers below use
US.01 as the template; the per-standard bases are listed at the bottom.

## The flight, in teaching order

| # | Flight phase | Mission Book (reader) | Teacher Deck slide | Flight Log write-point |
|---|--------------|-----------------------|--------------------|------------------------|
| 1 | **Climb · Mission Brief** (hook + set the goal) | Climb: Sam Calloway hook → "Open your Flight Log to Entry N" | `HOOK` (8) | **Entry N · Box 2** — put the mission in your own words + set your goal |
| 2 | **Climb · Pre-teach vocab** | Climb: EN/ES Word Wall | `KEY VOCABULARY / Word Wall` (13) | Word Wall terms (reader) |
| 3 | **Direct Instruction** (take notes) | — (content is read in the book) | `DIRECT INSTRUCTION` (9–11) | **Cornell Notes page US.0N** — *now cued on the first DI slide* ✓ |
| 4 | **Climb · Source preview → Wheels Down** | Wheels Down: primary source(s) | `PRIMARY SOURCE ANALYSIS` (12) | Source-It-First (WHO/WHEN/WHY) |
| 5 | **Guided → Independent practice** | — | `GUIDED PRACTICE` (14) → `STUDENT ACTIVITY` (15) | Entry N workspace — *now cued on the activity slide* ✓ |
| 6 | **Wheels Down · Make the call (CER)** | Wheels Down: "write it up with the CER process in your Flight Log" | (CER runs off the activity/check) | **Entry N · Boxes 1,3–5** — claim · evidence · connection + 4-3-2-1 self-grade |
| 7 | **Check for understanding** | — | `CHECK` (16) → `ANSWER REVEAL` (17) | — (self-grade on the rubric) |
| 8 | **Final Approach · Debrief + close** | Final Approach: MSgt "Muck" debrief → self-check → exit ticket | `WRAP-UP` (18) | Entry N self-check (1–4) + one-sentence exit ticket |

Plus, once per unit: Flight Log **Where-You-Stand**, **Flight Readiness**, **Geography
Waypoints**, and the **Arc-of-the-Union** plot — all reader-cued.

## Handoff verification

- **Deck DI ⇄ Flight Log Cornell — matched both ways.** The Flight Log Cornell page
  for each standard is built against the exact DI slide range, and those ranges match
  the deck 1:1: US.01→9–11, US.02→23–25, US.03→37–40, US.04→53–56, US.05→68–70,
  US.06→83–85, US.07→98–101. The deck now names the Flight Log on the first DI slide.
- **Deck Student Activity ⇄ Flight Log** — the activity strip now reads
  "Flight Log — write here: US.0N …" (was "Companion printable · Teacher Tools").
- **Reader ⇄ Flight Log** — the reader cues Entry N by box ("Box 2 at the Climb;
  Boxes 1,3–5 at Wheels Down"); the Flight Log entries carry exactly those boxes + CER.

## Note (one nuance, not a defect)

The deck's **Student Activity** deliverable is a graphic-organizer task (e.g. the
US.01 Cause-and-Effect Web). Its natural home is the **Graphic Organizer Toolkit**;
the deck cue sends the written response to the **Flight Log** in keeping with the
locked "all writing → the Flight Log" rule. Both are valid — the organizer is the
scaffold, the Flight Log is where the response is recorded.
