How to update when standards change

1. Download current TN Social Studies Standards from TDOE academic standards page
   (do not hard-code a year — use the current published document)
2. Open standards-matrix.html; add any new/changed standard codes to the matrix
3. Update scope-sequence.html to note which unit covers each new standard
4. Update eoc-validation.html if TCAP releases new frequency data
5. Update the question bank (question-bank.html) to add items for any new standard codes
6. Update the tagging_engine.py UNIT_SKILL_MAPS dict if new standards require new skill tags

1. Edit hipp.html directly for SOAPS/HIPP changes
2. Rebuild packet-a-skills.html using build_packets.py
3. If College Board updates APUSH CED, update the HIPP "College Board" citation
   in hipp.html Section 2 and in methodology.html Strategy 5

Activity and Inquiry Packets (Packet B)

1. Edit OPEN_INQUIRY_TASKS list in build_packets.py
2. Run: python3 /home/claude/build_packets.py
3. Copy outputs to /home/claude/ttt-tagged/ and /mnt/user-data/outputs/

Teacher Scaffolds Packet (Packet C)

1. Edit PACKET_C string in build_packets.py for legal sidebar updates
2. Edit PTG_SAMPLE dict for Priority Teaching Guide updates
3. Run: python3 /home/claude/build_packets.py

Adding a new unit or modifying unit content

1. Edit the appropriate unit-N.html file directly
2. Run tagging_engine.py to re-apply data attributes:
   python3 /home/claude/run_tagging.py
3. Rebuild ZIP:
   python3 /home/claude/build_final_zip.py
