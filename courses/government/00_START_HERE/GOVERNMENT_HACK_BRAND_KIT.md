# Government Hack™ — Brand Kit Spec

Paste these into a new Canva **Brand Kit** named **"Government Hack"** (Brand Hub → Brand Kits → Add new), then apply it to the Unit 1 Teacher Deck and Organizer Toolkit designs. Values match what is already baked into every generated page, so applying the kit keeps the deck/organizers pixel-consistent.

## Colors
| Role | HEX | Use |
|---|---|---|
| **Navy** (primary) | `#1B2A4A` | Headers, titles, primary text, dark label bands |
| **Red** (accent) | `#B22234` | Accent rules, "skill" chips, emphasis, the 4px header underline |
| **Gold** (secondary) | `#C89B3C` | Eyebrow labels, "reproducible" badges, Tennessee ★, left borders |
| **Cream** (surface) | `#F7F5EF` | When·Why strips, teacher-note strips, soft backgrounds |
| White | `#FFFFFF` | Writable areas, page background |

**Light tints** (writable surfaces / fills): navy `#EEF1F7` · red `#FBEEEF` · gold `#FAF3E2` · green `#EAF2EC`
**Utility:** rule/border `#CBD2DE` · muted text `#5A6579` · writing-line `#C4CCDA`

## Fonts
- **Headings / titles:** Georgia (serif). Canva equivalent if needed: *Lora* or *Playfair Display*.
- **Body / labels / UI:** Helvetica Neue → Arial. Canva equivalent: *Archivo* or *Work Sans*.
- Eyebrow/kicker text: uppercase, letter-spacing ~0.14em, bold, gold or red.

## Logo & wordmark
- Wordmark: **Government Hack™** — navy, bold sans; the ™ stays superscript.
- Footer lockup (every page): **Government Hack™ · © 2026 TroopToTeacher Technologies LLC**
- Course series eyebrow: **Government Hack Course Series · TroopToTeacher Technologies LLC**

## Recurring components (already in the build)
- **Header band:** navy background, gold eyebrow, Georgia title, 4–5px **red** bottom rule.
- **When·Why strip:** cream fill, 5px gold left border, ends in an italic cited evidence hook.
- **Reproducible badge:** gold outline, gold text, "✓ Reproducible".
- **Tennessee Connection:** gold ★ badge — the "signature move."
- **UDL · MTSS strip:** navy header, 3 columns (Scaffold / Extend / Show it your way).

## Guardrails (brand-level)
- Never print the source district name or "WCS" anywhere.
- Writable areas stay light; dark bands are labels only.
- Source-of-truth only — no invented facts, citations, or claims of state approval.
- Palette is print-first and grayscale-legible (WCAG-AA contrast).
