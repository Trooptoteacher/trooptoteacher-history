# Government Hack™ — District Print Package

Print-ready PDFs for **Foundations of Constitutional Government** (TN U.S. Government & Civics, GC.01–GC.35). Everything here is a locked PDF — download, print, photocopy, hand out. No app or login required.

**Read `_QC_REPORT.md` first** for the release verdict and the short fix list.

## Print tips
- **Duplex (two-sided)** the workbooks — halves the paper.
- **Answer keys** are only in `TEACHER/…_Assessment_Book_Teacher.pdf`. Never hand the Assessment Book to students.
- **Large-print** is best offered on demand, not as a class set (see QC report).
- **Do not** photocopy anything in `PRINT-SHOP_COVERS/` for classroom use — those are for a perfect-bound print run.
