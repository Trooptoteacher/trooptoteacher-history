# The Standard — TroopToTeacher Technologies / U.S. History Hack

> **Don't just learn history. Hack it.**
> _The curriculum that was built for results, not revenue._
> **Mission over margin.**

_This is the standing doctrine for every build decision. Read it before asking a scope or
design question: if the question has a right answer, this document is the answer._

## Why we exist

**Pearson and McGraw-Hill were built to make money. TroopToTeacher Technologies and History Hack
were built to make a difference.** The product is not measured against what sells — it is measured
against what actually teaches. Ours is going to be better, and more effective for students, than
anything on the market. That is the bar. Not parity. Better.

## The decision rule (default answer to any "which way?" question)

When a scope, design, or trade-off question has a right answer, the answer is whatever maximizes,
in this order:

1. **100% alignment** — workbook ↔ teacher deck ↔ student deck ↔ standards, with zero gaps. Every
   activity resolves to an exact slide; every taught segment has a home in every piece.
2. **TDOE Schedule F** — the Social Studies Instructional Materials Scoring Rubric is the ruler.
   Content accuracy (Policy 2.600) is foundational and non-negotiable. Score as-built, honestly.
3. **Best path to state adoption** — highest integrity, highest quality. Build what a TDOE reviewer
   and a real classroom teacher would both call the strongest material they've seen.

Do **not** ask the user to arbitrate between these — default to the adoption-grade choice and
proceed. Only surface a question when it is a genuine fork that Schedule F and alignment do **not**
settle (a true pedagogical or editorial judgment call), and even then, lead with the recommendation.

## What that means in practice

- Accuracy is foundational — every date, number, name, statute, case, and figure verifiable to a
  primary/authoritative source. No known error ships. When unsure: cut it or caveat it.
- Alignment is a pass/fail bar, not a nicety. A student must follow the lesson with zero guesswork.
- Commercial-use-safe sourcing only (PD / US-gov / CC0 / CC-BY; no share-alike, no permission-gated).
- UDL 3.0 + MTSS built in so the ceiling never lowers for any learner — supports add paths, never
  replace the goal, and never stand in for an IEP/504.
- Honesty doctrine: report what is done, what is held, and every gap — plainly. Never overclaim.
