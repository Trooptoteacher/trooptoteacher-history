## Exact blocker

The only Commons candidate identified in the verified sourcing manifest,
`EUROPE 1929-1938 POLITICAL MAP` (base file by Jan Humpolík; derivative work by
Commons user Alokasta), is licensed **CC BY-SA 3.0** (share-alike / "viral"
license). Republishing or adapting this file in a commercial, sold History
Hack product would legally require the derived page/product itself to be
released under CC BY-SA 3.0 — an unacceptable license contamination for a
commercial K-12 curriculum product.

- Commons page: https://commons.wikimedia.org/wiki/File:EUROPE_1929-1938_POLITICAL_MAP.svg
- Direct file URL (NOT downloaded, NOT used): https://upload.wikimedia.org/wikipedia/commons/9/9f/EUROPE_1929-1938_POLITICAL_MAP.svg
- License URL: http://creativecommons.org/licenses/by-sa/3.0/
- License terms confirmed via Wikimedia Commons API (`prop=imageinfo&iiprop=extmetadata`): LicenseShortName "CC BY-SA 3.0", Copyrighted=True, AttributionRequired=true, share-alike=YES.

No image binary for this rejected file has been downloaded or stored in this package, per instructions.

## Candidate/safer path identified in the manifest

**USMA West Point Digital History Center**, "German Expansion, 1936-39":
https://dhc.westpoint.edu/wp-content/uploads/sites/6/2025/01/WWIIEurope02.jpg
(via https://dhc.westpoint.edu/atlases/)

This map is a U.S. Military Academy Department of History work (likely a
U.S. Government work) but the atlas index page publishes **no explicit public
domain or license statement**, and explicitly asks users to contact
Mr. Jeff Goldberg ((845) 938-2264) for reprint permission before commercial
reuse. This is the same permission blocker documented for US.46 below.

be shipped for US.45's map component. (Note: the US.45 **data graphic**,
