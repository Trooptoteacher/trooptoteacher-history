# Unit 6 (WWII) — Visual Assets drop zone

This folder is where the **maps, data graphics, and primary-source images** for Unit 6 (US.45–US.58)
get collected before they're placed into the decks (and, sparingly, the workbook). The workbook stays
lean/pedagogy-forward; **the visuals live in the decks — especially the student deck** (the at-home
review copy).

## How to use this folder
1. Open `SOURCING_MANIFEST.md` — it lists, per standard, each asset with a **verified source link**,
   its **license**, the **attribution string**, and a **suggested filename**.
2. Download each asset (drag-and-drop, or point a download agent at the links).
3. Drop the file into the matching `US.<nn>/` subfolder, **named exactly as the manifest's
   `suggested_filename`** so the build scripts can find it.
4. Keep the source link + license with the file (the manifest is the record; don't lose it — it's
   what makes commercial use defensible at adoption).

## Naming convention
`US.<nn>_<short_descriptor>.<ext>` — e.g. `US.50_dday_normandy_map.jpg`, `US.56_manhattan_project_sites_map.jpg`,
`US.58_cordell_hull_portrait.jpg`. Lowercase, underscores, no spaces.

## License policy (LOCKED — this is a paid product; commercial use is required)
**Allowed:** U.S. federal government works (public domain — NARA, Library of Congress, U.S. Army CMH,
West Point/USMA atlases, Census, BLS, DOE, presidential libraries); works old enough to be public
domain; CC0; and CC BY / CC BY-SA (with attribution).
**Never:** Getty, Alamy, Shutterstock, Britannica, Statista, textbook publishers, "editorial use only,"
or anything with unclear rights.

**Data graphics:** where a clean PD chart doesn't exist, the manifest points to the underlying
**public-domain dataset** (Census/BLS/official histories) — build the chart from that so the graphic
itself is unambiguously ours.

## Before downloading — de-dupe
Cross-check against any existing Unit 6 image library in Google Drive first, so we don't re-source
assets you already have vetted.
