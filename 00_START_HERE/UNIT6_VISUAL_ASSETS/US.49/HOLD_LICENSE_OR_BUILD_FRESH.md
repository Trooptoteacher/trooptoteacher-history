## Exact blocker

`Map of participants in World War II` (Commons user Svenskbygderna, dated
2020-06-03), is licensed **CC BY-SA 4.0** (share-alike / "viral" license).

- Commons page: https://commons.wikimedia.org/wiki/File:Map_of_participants_in_World_War_II.svg

- License terms confirmed via Wikimedia Commons API: LicenseShortName
  "CC BY-SA 4.0", Copyrighted=True, AttributionRequired=true, share-alike=YES.

Using or adapting this file in a commercial, sold History Hack product would
require the derivative product/page to itself be released under CC BY-SA 4.0
— unacceptable for a commercial K-12 curriculum product. No image binary for
this rejected file has been downloaded or stored in this package.

## Candidate/safer path identified in the manifest

**No public-domain substitute of an Allies/Axis/neutral world map was found**
in the verified sourcing session. The closest federal options are USMA
West Point theatre maps — "Pacific and the Far East"
(https://dhc.westpoint.edu/wp-content/uploads/sites/6/2025/01/WWIIEurope44.jpg)
and "Europe and the Middle East"
(https://dhc.westpoint.edu/wp-content/uploads/sites/6/2025/01/WWIIEurope43.jpg)
— but these are regional theatre maps, not a single Allies/Axis/neutral world
map, and are additionally subject to the same West Point reprint-permission
blocker documented for US.46 (contact Mr. Jeff Goldberg, (845) 938-2264).

## Required action

1. **Build fresh** (recommended): produce an original world map on a
   public-domain/original basemap, color-coding countries as Allied power,
   Axis power, or neutral. Belligerency status by country is a historical
   fact, not protected expression, and may be independently re-plotted.
2. Alternatively, obtain written West Point permission (see US.46 hold) and
   assemble a composite from the two theatre maps — but this does not by
   itself produce a single world-participants map and is not recommended.

Until one of the above is completed and re-verified, no image asset should
be shipped for US.49.
