- **Factual caveats — MODIFIED FILE / ANACHRONISM CAVEAT (REQUIRED):**
  - **This file is a MODIFIED version of the original Ziemke map**, not the original as-printed 1975 figure. The Commons description states it was "modified to show the inner German border and the zone from which Allied forces withdrew in July 1945." The Soviet zone is shown in red, the inner German border in heavy black, and the Anglo-American withdrawal zone in purple.
  - **Anachronism:** the provincial boundaries shown are pre-Nazi Weimar-era boundaries, which is anachronistic for a map captioned as depicting the 1945 occupation zones.
  - **Withdrawal-line caveat:** the German-language description on the Commons file page notes that the British withdrawal line is **not** drawn on this version, even though the American withdrawal line is shown — do not assume both Western Allied withdrawal lines are depicted.
  - Any caption or slide using this map MUST identify it as a modified/annotated version of the original Ziemke figure and note the anachronistic base boundaries and the missing British withdrawal line.
