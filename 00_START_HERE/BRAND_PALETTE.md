# TroopToTeacher Technologies — Brand Palette (CANONICAL)

> **America 250 Palette.** This is the single source of truth for brand color across every
> deliverable and skill — workbooks, decks, artifacts, web. It **retires** the ad-hoc tokens that
> caused drift (`#1B2A4A`, `#0A1F3C`, `#C89B3C`). Do not introduce those; use the tokens below.

## Core palette (use these four for curriculum)

| Token | Name | Hex | Primary use |
|---|---|---|---|
| `--heritage-blue` | Heritage Blue | `#1F3A5F` | Headings, banners, dark sections, structure |
| `--patriot-red` | Patriot Red | `#B22234` | Callouts, highlights, dividers, emphasis |
| `--founders-cream` | Founders Cream | `#F8F5EF` | Main background (dominant) |
| `--muted-gold` | Muted Gold | `#C9A227` | Restrained accents, premium details (sparingly) |

**Usage rule:** cream is the **dominant background**; **blue** carries structure; **red** marks
emphasis; **gold** is used **sparingly** for premium accents. One color dominates — never give all
four equal weight.

## Broader brand (site / marketing / special surfaces)

| Token | Name | Hex |
|---|---|---|
| `--liberty-navy` | Liberty Navy | `#1A2332` |
| `--phoenix-gold` | Phoenix Gold | `#F9A825` |
| `--america250-deep-blue` | America 250 Deep Blue | `#002858` |

Liberty Navy suits very dark UI surfaces; Phoenix Gold and America 250 Deep Blue are for marketing
and special/hero surfaces — not the default curriculum body palette.
