# Unit 6 — Teacher Edition Workbook (Answer Key) — Build Status

**Files:** `Unit6_Teacher_Workbook_AnswerKey.docx` (editable) · `.pdf` (print/review)
**What it is:** the FULL student workbook (all 190 pp, identical layout) as an annotated
**Teacher Edition** with correct answers marked inline — the in-class answer-key copy.

## How it differs from the student workbook
- Cover + running header marked **TEACHER EDITION — ANSWER KEY · keep separate from students** (red).
- **Practice quizzes (Activity 6):** the correct option on every item is marked with a green ✓ and
  green text (56 items = 14 standards × 4). Answers read from each standard's own "CHECK YOURSELF"
  key line (ground truth), so US.45's original quiz keys correctly too.
- **Exit tickets:** the correct option is marked green ✓, and the footer line is replaced with
  `✔ ANSWER: X — <rationale>` (14 standards).
- Worked CER/HIPPO models already appear on the support pages (shared with the student book).

## How it was built
Derived from the student workbook `.docx`; marking uses green color + ✓ (no bold) to avoid changing
line width (bolding caused a page to spill). US.45's Activity 6 spacing was tightened slightly to
absorb the ✓ prefixes. Rendered and QC'd: **190 pp, zero blank pages.**

## Relationship to the Teacher Guide
The Teacher **Guide** (`UNIT6_TEACHER_GUIDE_BUILD/`) is the compact companion (pacing, MTSS, CER
rubric, compiled keys + rationale + reteach). This Teacher **Workbook** is the full annotated book.
Use the Guide for planning; use this for answers-in-context while circulating.
