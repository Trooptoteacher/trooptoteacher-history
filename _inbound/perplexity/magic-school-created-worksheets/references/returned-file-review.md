# Returned File Review

## Intake

- [ ] Prompt ID is identifiable.
- [ ] Expected files were uploaded.
- [ ] Word files are editable.
- [ ] English student, Spanish student, teacher key, and implementation note are present.

## Alignment

- [ ] Standard ID and wording are correct.
- [ ] Worksheet measures the stated learning target.
- [ ] SSP activity matches the listed practice.
- [ ] Success criteria are observable.
- [ ] MagicSchool followed the selected worksheet type, target, focus, perspectives, and source set without substituting its own.

## Historical and Source Integrity

- [ ] Dates, names, claims, and statistics are accurate.
- [ ] Quotations match authoritative sources.
- [ ] Primary sources are cited.
- [ ] Images and third-party assets have rights information.
- [ ] No proprietary commercial material was copied.

## Instructional Supports

- [ ] UDL engagement option is meaningful.
- [ ] Representation reduces barriers.
- [ ] Action/expression options assess the same target.
- [ ] MTSS supports match the assigned tier.
- [ ] Scaffold fading is practical.
- [ ] WIDA supports match L1–2, L3–4, and L5–6.
- [ ] Supports preserve rigor.

## Bilingual and Accessibility

- [ ] English and Spanish editions have equivalent content.
- [ ] Spanish is accurate and natural.
- [ ] Directions are screen-reader friendly.
- [ ] Headings and reading order are logical.
- [ ] Tables have headers.
- [ ] Contrast and writing space are sufficient.
- [ ] No instruction relies on color alone.
- [ ] Alt text is supplied or recommended.

## File and Release Quality

- [ ] Teacher key matches the student edition.
- [ ] Official History Hack branding is applied.
- [ ] Filename follows the unit convention.
- [ ] One authoritative editable Word original is retained.
- [ ] PDF export matches the Word file.
- [ ] File opens and prints correctly.
- [ ] Manifest and generator connection point to the physical file.

Classify the result:

- **Keep**: ready after routine branding/export
- **Revise**: usable but needs corrections
- **Merge**: strongest parts should be incorporated into an existing authoritative file
- **Reject**: inaccurate, duplicative, inaccessible, or structurally unsuitable
