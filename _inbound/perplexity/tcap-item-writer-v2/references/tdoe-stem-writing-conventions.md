# TDOE Stem Writing Conventions for TCAP Social Studies

Sources:

- TCAP Assessment Committee review standards (Pearson/ETS conventions)

## Core Stem Rules

### 1. Complete Question Stems
Every stem must be a complete, self-contained question ending with a question mark. The student should understand exactly what is being asked before reading the options.

**Correct**: "Which factor most directly contributed to the growth of labor unions in the late 1800s?"
**Incorrect**: "The growth of labor unions in the late 1800s..."

### 2. Main Idea in the Stem
The main idea, context, and any qualifying information must appear in the stem, not in the options. The stem carries the cognitive load; options are short answers.

**Correct**: "During the Progressive Era, which reform most directly addressed unsafe working conditions in factories?"
**Incorrect**: "Which of the following is true about the Progressive Era?"

### 3. Avoid Negative Stems
Do not use NOT, EXCEPT, LEAST, or other negative constructions unless absolutely necessary to assess the standard. When unavoidable:
- **Bold** the negative word
- Use only when the standard specifically requires students to distinguish exceptions
- Never combine negative stem with negative options

**Acceptable (rare)**: "Which action was **NOT** a result of the Treaty of Versailles?"
**Preferred alternative**: "Which action resulted from the Treaty of Versailles?" (test the positive directly)

### 4. No Trick Items
Items must test content knowledge, not reading comprehension tricks or verbal cleverness. If a knowledgeable student could miss the item due to tricky wording rather than content misunderstanding, the item fails.

### 5. No "All of the Above" / "None of the Above"
AOTA and NOTA are prohibited in TCAP items. They:
- Reduce discrimination (students can use partial knowledge to eliminate)
- Create logical problems (if one option is partially correct, is AOTA correct?)
- Do not measure specific misconceptions

### 6. Four Options for MC
All multiple-choice items have exactly 4 options (A, B, C, D). No more, no fewer.

### 7. Two Correct for MS
Multiple-select items must have exactly 2 correct answers from a pool of options (typically 5–6). The stem must include "**Select TWO answers**" or equivalent clear instruction.

### 8. All Distractors Tagged with Misconception Code
Every distractor must have a documented misconception code from the distractor taxonomy. No filler distractors. If you cannot articulate what specific misunderstanding would lead a student to choose a distractor, the distractor needs revision.

## Stimulus Conventions

### Primary Source Stimuli
- Use public domain sources only (pre-1929 or government documents)
- Cite the source with author, title, date, and archive/collection
- Excerpt must be long enough to support the question but short enough for timed testing
- Never alter the source text (ellipses for omissions are acceptable)

### Graphics and Maps
- All graphics must be described with alt text for accessibility
- Maps must include title, date, legend, and compass rose
- Data tables must have clear headers and units
- Graphics must add to the question — never decorative

### Document-Based Questions (DBQ)
- Use 2–3 sources maximum per item set
- Sources should present different perspectives or types of evidence
- Students must synthesize across sources, not just summarize one
- Use HIPP (Historical context, Intended audience, Purpose, Point of view) or SOAP (Speaker, Occasion, Audience, Purpose) analysis frameworks

## Option Construction

### Parallel Structure
All options must be:
- Similar in length (within ~20% of each other)
- Grammatically parallel
- Fitting with the stem to form a complete, correct sentence (if open stem format)

### Key Position Distribution
Across a set of items, correct answer positions should be approximately evenly distributed across A, B, C, D. No patterns.

### Distractor Strength
Option D must be as strong and plausible as Options A, B, and C. Test writers often fatigue on the last distractor — this is the most common Committee review flag.

## TCAP-Specific Formatting

- All TCAP items are delivered via TestNav (online platform)
- Technology-enhanced items may use drag-and-drop, hot spot, or matching formats
- Reading passages should not exceed what a student can process in the allotted time (~90 seconds per item on average)
