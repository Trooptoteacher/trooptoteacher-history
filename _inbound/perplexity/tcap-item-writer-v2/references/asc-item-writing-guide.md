# ASC Item Writing Guide 2025 — Key Principles

Source: [ASC Item-Writing Guide 2025](https://assess.com/docs/ASC_Item-Writing-Guide_2025.pdf)

## Validity Chain

Job analysis → Specifications → Items → Scores → Interpretations

Each item must specifically measure the intended construct (construct-relevant variance) and avoid measuring unrelated traits (construct-irrelevant variance).

### Threats to Validity
- Item does not reflect specifications
- Item is misaligned to the assessed standard
- Item is unclear or confusing
- Item overlaps content areas unintentionally
- Item introduces systematic bias

## Stem Writing Rules

| Rule | Do | Avoid |
|------|-----|-------|
| Focus | One knowledge concept per item | Multiple objectives in one item |
| Problem | Clearly defined, complete question | "Which of the following is true?" |
| Alignment | Map to specific standard/spec | Items outside the assessed standard's scope |
| Vocabulary | Common, grade-appropriate terms | Jargon, slang, unnecessarily complex language |
| Phrasing | Positive framing | NOT, LEAST, EXCEPT (unless essential and bolded) |
| Independence | Self-contained, stand-alone | Dependency on other items |
| Extraneous info | Only relevant information in stem | Window dressing that adds reading load without purpose |

## Option Writing Rules

| Rule | Do | Avoid |
|------|-----|-------|
| Homogeneity | All options address same content domain | Mixed content types across options |
| Parallelism | Similar length, grammatical structure | Key significantly longer than distractors |
| Fit | All options fit grammatically with stem | Grammar cues that reveal the answer |
| Order | Logical ordering (chronological, numerical) | Random ordering that confuses |
| Plausibility | Every distractor targets a specific misconception | Made-up terms, absurd options |
| Prohibited | — | ALL OF THE ABOVE, NONE OF THE ABOVE, ALWAYS, NEVER |

## Key (Correct Answer) Rules

- Only one defensible correct answer per MC item
- Similar in length, structure, and specificity to distractors
- Does not contain giveaway keywords from the stem
- Distributable across positions (A/B/C/D) without pattern

## Distractor Rules

- Each distractor targets a specific, documentable misconception or common error
- Distractors use similar terminology and specificity as the key
- No trick distractors — every distractor should be chosen by a student who has a specific misunderstanding
- Distractor rationale must be recordable and defensible

### Distractor Misconception Categories (for Social Studies)
| Code | Category | Description |
|------|----------|-------------|
| PK | Prior Knowledge Error | Student confuses with a different but related concept |
| MC | Misconception | Student holds a documented historical misconception |
| PE | Partial Evidence | Student uses some correct information but reaches wrong conclusion |
| NE | Nearby Error | Student selects an answer from the correct time period or topic but wrong specific fact |
| CA | Causal Attribution | Student misattributes cause or effect |
| AN | Anachronism | Student places event, person, or concept in wrong time period |
| OG | Overgeneralization | Student applies a broad generalization incorrectly |

## Constructed Response Guidelines

- Envision the scoring rubric before writing the item
- Define what constitutes a complete, partial, and inadequate response
- Ensure the prompt elicits the targeted cognitive process
- Consider scoring cost/reliability tradeoff

## Item Review Checklist (from Appendix A)

1. **Content Alignment**: All items align to specs; cover important KSAs; mapped to standard
2. **Clarity/Conciseness**: Stems clear, no extraneous info, simple language for population
3. **Structure/Format**: Stem defines problem positively; consistent design; key is only fully correct answer
4. **Answer Options**: Distractors plausible, similar length/structure, logical order, no giveaway keywords
5. **Bias/Fairness**: No demographic bias; neutral cultural context; demographics only when necessary
6. **Scoring**: Key defensible with reference; rubric defined for CR; graphics cited
7. **References**: Rationale and source citation for correct answer documented
