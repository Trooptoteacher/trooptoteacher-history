# Master Compliance Checklist

Use this checklist to track the vendor's compliance status across all required areas. Update this tracker each session and flag any changes.

## How to Use

- Copy this template into a workspace file for the specific vendor (e.g., `history-hack-compliance-tracker.md`)
- Update statuses as compliance work progresses
- Review at the start of every session

## Status Legend

| Icon | Meaning |
|------|---------|
| ✅ | Fully compliant — documentation complete and verified |
| ⚠️ | Partially compliant — work in progress or gaps identified |
| ❌ | Not compliant — must be addressed before submission |
| 🔲 | Not yet assessed |
| N/A | Not applicable to this vendor/product |

## Severity Definitions for Gap Analysis

| Severity | Definition | Timeline |
|----------|-----------|----------|
| **Blocker** | Cannot submit form until resolved. Legal or regulatory requirement. | Must resolve immediately |
| **High** | Likely to cause rejection or significant delay. | Resolve within 1-2 weeks |
| **Medium** | May raise concerns but unlikely to block approval alone. | Resolve within 30 days |
| **Low** | Best practice recommendation. Strengthens application. | Resolve within 90 days |
