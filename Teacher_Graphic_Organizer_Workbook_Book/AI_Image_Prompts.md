# U.S. History Hack™ — Graphic Organizer Toolkit (Bound Book)
## AI image-generator prompt pack — cover · spine · back cover · 10 unit separators

**Use these as-is in your image creator.** Every prompt shares the same *Brand Block* so the whole book
reads as one designed system: gold line-engraving on deep navy, red accents, cream banners, dignified
"veteran-educator field manual / WPA-almanac" feel — never cartoonish.

- Text-capable generators (Ideogram, Adobe Firefly, DALL·E-3 / GPT-image, Recraft) → keep the baked-in
  text; they spell reliably.
- Midjourney / pure art models → append the **[NO-TEXT VARIANT]** line so it renders art only, and you
  set the type yourself in Canva (brand kit `kAG39-EGTcM`).
- Always generate at **300 DPI**, request a **0.125 in bleed**, and keep titles inside a **0.5 in safe margin**.

## ★ BRAND BLOCK (paste at the top of every prompt)

```
Brand: "U.S. History Hack" by TroopToTeacher — a dignified, veteran-founded American history
teaching brand. Visual style: vintage letterpress / WPA-poster / engraved field-manual aesthetic.
Palette EXACTLY: deep navy #1B2A4A (primary background), flag red #B22234 (accent only),
antique gold #C89B3C (line art, rules, wordmark), warm cream #F7F5EF (banners/paper), white.
Fine gold line-engraving and linocut textures on navy; subtle aged-paper grain; crisp thin gold
rules and corner brackets; one clean gold five-point star as the recurring insignia. Typography:
elegant classic serif for titles (Trajan/Caslon feel), clean sans for small labels. Composition
is centered, symmetrical, editorial, and calm — like an official almanac or military field guide.
Mood: authoritative, trustworthy, timeless, patriotic-restrained. NOT glossy, NOT neon, NOT 3D,
NOT cartoon, no waving flags, no photoreal faces, no clip-art, no stock swooshes.
```

**Negative prompt (append to all):**
`neon colors, gradients, drop shadows, 3D render, glossy plastic, cartoon, clip art, waving flag,
photorealistic people, cluttered, busy, low-contrast, misspelled text, gibberish letters, watermark,
modern UI, emoji`

## 4 · UNIT SEPARATORS — 8.5 × 11 in portrait × 10

Same template every time so the ten tabs feel like a set — only the **star count / unit number**, the
**title line**, the **years**, the **standard range**, and the **[MOTIF]** change. Keep everything else identical.

### Separator TEMPLATE prompt
```

double gold rule frame with engraved corner brackets. Top center: a gold banner "U.S. HISTORY HACK™".
Dominant center element: a large engraved gold roundel medallion on navy containing [MOTIF], rendered

"TroopToTeacher Technologies LLC" in gold small-caps. Symmetrical, dignified, consistent with a matched
set of dividers.
```
**[NO-TEXT VARIANT]** *Render only the gold roundel with [MOTIF] and a blank cream title banner; no lettering.*

**Consistency tips**
- Keep the **medallion size and placement identical** across all ten; only the interior motif changes.
- Ask for each motif "in the same fine gold line-engraving style, single red accent, on navy #1B2A4A"

- Generate the divider set in **one session/seed family** if your tool supports it, for uniform texture.
- If a motif comes out busy, add `simpler, fewer elements, more negative space` — dividers should read
  instantly at a glance.
