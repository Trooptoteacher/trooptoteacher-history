How to Use This Activities Package

Each unit in this package includes three versions of the same core activity, designed around the unit's primary source spotlight and central historical thinking skill. All three versions address the same essential question and standards — the differentiation is in scaffolding and depth, not in the historical content or expectations for evidence-based reasoning.

Version A — Modified / ELL
Best for: Students with IEPs, below-level readers, and English Language Learners.

Features: Simplified source text · Bilingual vocabulary (English/Spanish) · Sentence stems · Graphic organizer with labeled boxes · Shorter constructed response (1 paragraph) · SOAPS with guiding prompts
Version B — On-Level
Best for: Most students in a standard 11th-grade U.S. History course.

Features: Original source text · Full SOAPS + HIPP analysis tables · Four-box graphic organizer · Constructed response (1–2 paragraphs) · Synthesis requirement · Tennessee EOC-aligned vocabulary
Version C — Advanced
Best for: Students preparing for AP U.S. History or accelerated tracks.

Features: Original source text · Full HIPP with argumentative connection requirement · Extended DBQ-style prompt (3–5 paragraphs) · Cross-source synthesis required · Self-assessment checklist · Vocabulary challenge (complete from memory)

Differentiation Notes

  • You do not need to assign all three versions. Many teachers give Version B to most students and Version A to specific students as an accommodation, without distributing Version C unless students are formally enrolled in an AP track.
  • Versions can be mixed across activities. A student who reads below grade level but reasons at a high level might receive Version A vocabulary support but Version B analytical tasks.
  • For ELL students: The bilingual vocabulary in Version A is a support, not a crutch. Encourage students to write their responses in English, using the Spanish translations only when needed to understand the term.
  • For SWD: Version A is designed with extended time in mind — the simplified text and graphic organizers reduce processing load without reducing cognitive demand. Consider chunking the activity across two class periods if needed.
