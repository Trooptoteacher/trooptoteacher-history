# The Platinum Standard

> **Don't just learn history. Hack it.**
> _The curriculum that was built to make a difference, not to make money._
> **Mission over margin.**

## What "Platinum" means (and why the name matters)

**Platinum = the canonical, current, best-of-best.** When a template, baseline, reference, or skill
is labeled **Platinum**, it is the authoritative, most-up-to-date version — the thing every new build
is measured against and built to, **going forward**. If you are choosing what to copy or extend,
choose the Platinum one.

**Gold = where it started.** The original baseline/pattern (e.g., the Unit 1 gold-standard origin).
Gold is honored as the seed, but it is **superseded** by Platinum. Never build a new course to Gold
when a Platinum standard exists.

**Rule:** the Platinum tier is identified explicitly — in `BUILD_STANDARD.md`, the skills registry,
the `*_PLATINUM_STANDARD.md` docs, and the `PLATINUM_ADOPTION_AUDIT.md` trail. A build isn't done
until it meets Platinum — not Gold, not parity.

## Future-ready (build once, scale to every course)

Everything Platinum must be **future-ready**: built to scale across all remaining courses, not as a
one-off. A skill, template, or engine is Platinum only if it is —
- **Reusable & parameterized** — driven by standards/data input, not hard-coded to one unit or course.
- **Standard-driven** — reads the canonical guardrails here, so a change to the standard propagates
  to every future build instead of being re-litigated.
- **Repeatable & self-checking** — ships with its QC gate so quality is enforced the same way every time.
- **Extensible** — a new course (Government, Economics, World History, …) plugs in without a rewrite.

If a proposed build would only work for the unit in front of you, it is not yet Platinum — generalize it.

## The mission (why this exists)

**Pearson and McGraw-Hill were built to make money. TroopToTeacher Technologies and History Hack were
built to make a difference.** The product is measured against what actually teaches — it must be
**better, and more effective for students,** than anything on the market. The bar is *better*, not parity.

## The decision rule (default answer to any "which way?" question)

When a scope/design/trade-off has a right answer, choose whatever maximizes, in order:

1. **100% alignment** — workbook ↔ teacher deck ↔ student deck ↔ standards, zero gaps; every activity
   resolves to an exact slide; every taught segment has a home in every piece.
2. **TDOE Schedule F** — the Social Studies rubric is the ruler. Content accuracy (Policy 2.600) is
   foundational and non-negotiable. Score as-built, honestly.
3. **Best path to state adoption** — highest integrity, highest quality; what a TDOE reviewer *and* a
   real classroom teacher would both call the strongest material they've seen.

**Do not ask the user to arbitrate between these** — default to the adoption-grade (Platinum) choice
and proceed. Only surface a question for a genuine fork Schedule F/alignment doesn't settle — and lead
with the recommendation.

## How it shows up in the work

- Accuracy is foundational; no known error ships. Unsure → cut it or caveat it.
- Alignment is pass/fail — a student follows the lesson with zero guesswork, or it isn't done.
- Commercial-use-safe sourcing only (PD / US-gov / CC0 / CC-BY; no share-alike, no permission-gated).
- UDL 3.0 + MTSS built in — supports add paths, never lower the ceiling, never replace an IEP/504.
- Honesty doctrine — report what's done, held, and every gap plainly. Never overclaim.
