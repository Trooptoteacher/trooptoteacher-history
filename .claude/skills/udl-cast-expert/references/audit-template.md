# UDL 3.0 Audit Template

Use this template when producing a UDL audit of any existing artifact (workbook, slide deck, video, worksheet, lesson, unit, or product).

## Header

```
UDL 3.0 Audit — [Artifact Name]
Auditor: [Name/Agent]
Date: [YYYY-MM-DD]
Framework: CAST UDL Guidelines 3.0 (2024)
Learner variability profile: [Grade band, EL levels, IEP/504 categories, GT, cultural/linguistic context, other]
Firm learning goals: [The standards or mastery outcomes that must NOT change]
```

## Section 1 — Artifact Description

- What is the artifact? (Physical form, page count, digital/print, standalone or part of a set)
- What learners is it designed for?
- What learners is it likely to be used with in practice? (Often broader than the design intent)
- What decisions were made in the current design about mode, language, response format, pacing?

## Section 4 — Prioritized Gaps

List the ❌ items in equity-impact order (not numerical order):

1. **[Consideration #] [Title]** — Why this gap matters for THIS artifact and THESE learners. Which learners are excluded or under-served. Suggested design fix (1 sentence).
2. …

Prioritization heuristic:
1. Excludes learners with disabilities from mastery altogether
2. Forces EL/multilingual learners into English-only expression
3. Centers a single dominant perspective as neutral
4. Excludes learners' identities from valid content
5. Forces single mode of response

## Section 5 — Salvage Assessment

For each gap, mark:

- **SALVAGE** — The existing content is usable; only needs UDL wrapper (scaffolds, choice, alternate modes)
- **REDESIGN** — Content needs restructuring; UDL cannot be retrofitted
- **REPLACE** — Content is fundamentally exclusionary or misaligned; needs replacement

Prediction: most existing artifacts are 60-80% SALVAGE. Do not recommend REPLACE unless the content itself is the problem.

## Section 6 — Recommendations

Grouped by principle. Each recommendation must be:
- Artifact-level (not per-student accommodation)
- Traceable to a specific consideration
- Preserving the firm goal
- Producible by the current tooling / regen kit / engine

## Section 7 — Provable-Differentiation Evidence Stamps

For each recommended design change, specify what evidence artifact appears on the page/slide/screen so a curriculum director can point at it:
- WHAT is the design offering
- HOW it operates
- FOR whom (WIDA level, 504 category, IDEA modification, GT, general)
- EVIDENCE (which UDL consideration it maps to)

## Section 8 — Non-UDL Flags

Note anything the audit surfaced that is NOT a UDL question but needs separate handling:
- IEP modifications (lowered ceiling on standard) — route to SPED coordinator, not UDL redesign
- Content accuracy issues — route to subject-matter reviewer
- Standards misalignment — route to curriculum director
- Copyright/attribution issues — route to legal/licensing
