# Organizer catalog — what to reach for, and when

Match the organizer to the **task verb**. This table is also the content of the "Which Organizer, When"
Quick Guide (task → organizer → why) and drives which labeled organizer each standard gets. Don't force a
type onto a task it doesn't fit; add a new organizer if a task needs one.

| When the task asks students to… | Reach for | Why it works (cite) | ~Time |
|---|---|---|---|
| Compare **two** things | Venn (2) · T-chart | Overlap shows shared traits, sharpens differences (Marzano #1) | 10–15 |
| Compare **3+** on set criteria | Comparison matrix | Holds many cases against one yardstick; patterns pop (Marzano) | 15–20 |
| Trace **causes & effects** | Cause & Effect | Makes the chain of "why" visible (SSP.05) | 15–20 |
| Put events **in order** / change over time | Timeline (date LEFT of event) | Sequence exposes cause across time (SSP.05 chronology) | 15–20 |
| **Brainstorm** & connect ideas | Concept web | Surfaces prior knowledge; shows links to one hub (UDL schema) | 10–15 |
| **Summarize** — find the main point | Main Idea & Details | Separates the big idea from supporting detail | 10–15 |
| **Activate** prior knowledge & track learning | K-W-L | Sets purpose; metacognitive (UDL self-regulation) | 10–15 |
| **Learn a term** | Frayer | Deep word knowledge: meaning, traits, examples, non-examples (Marzano) | 10–15 |
| **Analyze a source** | HIPPO (or OPTIC) | A historian's routine for interrogating a document (SSP.02) | 15–20 |
| Make an **evidence-based claim** | C-E-R | Turns opinion into a defensible argument (SSP.04) | 20–25 |
| **Weigh two sides** / options | T-chart · Problem–Solution | Forces a decision resting on evidence from both sides | 15–20 |
| Get the **basics of an event** | 5 Ws | Fast, complete factual capture (SSP.01) | 5–10 |
| Connect the **nation → Tennessee** | ★ Tennessee Connection | Local ties make it stick — the signature move (UDL relevance) | 10–15 |

## Design notes per type (the "real visual" requirement)
- **Venn 2/3** — true overlapping circles (light tint fills, colored strokes), a gold center lens; labels
  and topic keys **outside/inside via SVG text**, faded region captions, dotted writing guides in lobes.
  Topics go in a legend row above (Venn 3) or SVG headers, never floating over the circle edges.
- **T-chart** — two label bands over tall lined wells + a synthesis strip; for labeled versions, seed each
  side with sourced prompts and add a ★ TN box where a tie exists.
- **Matrix** — CSS grid: colored column headers (options/cases) × navy row labels (criteria) × light
  writable cells + a "pattern/conclusion" row.
- **Cause & Effect** — causes (left) → center EVENT box → effects (right), arrows; or a numbered vertical
  chain for a policy sequence.
- **Timeline** — vertical spine with ticks; **date well on the LEFT of each event** (write the date, then
  the event); labeled versions pre-fill dates + event names, leave light wells for significance.
- **Concept web** — center hub (light "Central Idea" watermark over writing lines) + spokes to light outer
  bubbles; keep the hub label faint so there's room to write.
- **Main Idea & Details** — top MAIN IDEA band+well; a row of detail wells with up-arrows; a summary line.
- **KWL** — three equal columns (K navy / W red / L gold) over tall light lined wells.
- **5 Ws** — hub-and-spoke: center EVENT box (label strip carries "name it," well stays clear) → Who/What/
  When/Where/Why (+How) light wells; spokes as SVG lines.
- **Problem–Solution** — PROBLEM well → 2–3 solution options (each with a result/trade-off area) → decide
  → best-solution justification.
- **Frayer** — 2×2 quadrants with all four labels at the TOP of their quadrant; center oval holds the
  term near the top with write space below.
- **CER** — CLAIM → EVIDENCE (2–3) → REASONING, linked by arrows; light wells.
- **HIPPO** — a source-citation box on top, then H (historical context) · I (intended audience) · P (point
  of view) · P (purpose) · O (outside information), each a gold letter tile beside a light lined box.
- **Tennessee Connection** — national panel ↔ Tennessee panel linked by a "connects to" hub, then a
  "how are they linked?" band and a "why the local story matters" reflection.

## SSP Crosswalk (page 2 of each unit)
Map each practice to the organizers that build it and where it lives in the unit:
- **SSP.01 Collect Information** → 5 Ws, Main Idea & Details, KWL.
- **SSP.02 Critically Examine Sources** → HIPPO, CER.
- **SSP.03 Synthesize Data** → Comparison matrix, Concept web, Venn.
- **SSP.04 Construct & Communicate with Evidence** → CER, T-chart, Problem–Solution.
- **SSP.05 Develop Historical Awareness** → Timeline, Cause & Effect, Sequence.
- **SSP.06 Develop Geographic Awareness** → City × attribute matrix, Tennessee Connection.
