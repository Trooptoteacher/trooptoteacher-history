# Gateway Checks — Standards Coverage Reference

Load this reference when performing Stage 2 (Gateway Check 1) and Stage 3 (Gateway Check 2).

## Gateway 1: Standards Alignment Guide Verification

**Requirement:** Publisher must provide a Tennessee-specific Standards Alignment Guide.

**Checklist:**
- [ ] Document is titled or labeled as a standards alignment guide
- [ ] References Tennessee Social Studies standards specifically (not generic/national)
- [ ] Maps content to individual TN standard IDs (e.g., US.01, US.02)
- [ ] Includes page/section references for where each standard is addressed
- [ ] Covers the complete course scope (for U.S. History: Reconstruction through Modern Era)

**If any of the above are missing:** FAIL Gateway 1. Issue notice specifying what is missing.

## Standards Coverage Matrix Template

Use the following format when generating the Standards Coverage Matrix output:

```
| Standard ID | Standard Text (abbreviated) | Status | Evidence / Page Reference |
|-------------|----------------------------|--------|--------------------------|
| US.01 | Differing perspectives on Reconstruction | Met | Ch. 1, pp. 4-12 |
| US.02 | 13th, 14th, 15th Amendments | Partially Met | Ch. 1, p. 15 (14th Amend. treatment is thin) |
| US.03 | Freedmen's Bureau | Not Met | No coverage found |
```

**Status definitions:**
- **Met:** Standard is directly and substantively addressed with adequate depth.
- **Partially Met:** Standard is referenced or addressed but with insufficient depth, missing key elements, or only tangentially covered. Flag for rubric scrutiny.
- **Not Met:** Standard is absent from the material. This is a Gateway 2 blocker.

**Gateway 2 pass/fail:**
- PASS: Zero "Not Met" standards.
- FAIL: One or more "Not Met" standards. List all gaps.
