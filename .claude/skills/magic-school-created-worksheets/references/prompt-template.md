# Copy-Ready Prompt Template

Replace every bracketed field before giving the prompt to the user. No placeholder may ask the user to supply information the agent can retrieve.

```text
HISTORY HACK WORKSHEET DRAFT REQUEST

EXECUTION DIRECTIVE:
All instructional decisions and required information are supplied below. Do not ask follow-up questions. Do not offer a menu of worksheet types, objectives, sources, or perspectives. Create the complete requested package now.

PROMPT ID:
[Prepopulated ID]

UNIT:
[Prepopulated unit number and title]

STANDARD:
[Prepopulated standard ID]
[Exact verified official wording]

SOCIAL STUDIES PRACTICE(S):
[Prepopulated SSP code, official skill label, and how students will demonstrate it]

LEARNING TARGET:
[Prepopulated student-facing target]

SUCCESS CRITERIA:
[Prepopulated observable evidence]

WORKSHEET TYPE AND PURPOSE:
[One preselected asset type and its instructional purpose]

ASSESSMENT EVIDENCE:
[Prepopulated evidence this worksheet should produce]

HISTORICAL CONTENT FOCUS:
[One preselected focus and the required balance of economic, political, social, environmental, geographic, and cultural perspectives]

REQUIRED PERSPECTIVES:
[Preselected perspectives appropriate to the standard, including historically affected groups]

PRIMARY SOURCE OR CONTENT SET:
[For each source: creator, title/description, date, repository, stable URL, rights/license, and approved excerpt or image instruction. If no source is needed, state: "No primary source is required for this worksheet; use only the supplied content points below."]

REQUIRED CONTENT POINTS:
[Prepopulated historically verified ideas, vocabulary, events, and relationships the worksheet must address]

UDL 3.0 REQUIREMENTS:
- Engagement: [specific option]
- Representation: [specific option]
- Action and expression: [specific options]

MTSS REQUIREMENTS:
- Primary tier: [Tier 1, Tier 2, or Tier 3]
- Universal core expectation: [rigorous expectation for all students]
- Targeted scaffolds: [specific supports]
- Scaffold-fading plan: [how supports are reduced]
- Progress evidence: [what the teacher should observe or collect]

WIDA LANGUAGE SUPPORTS:
- L1–2: [specific word bank, visual support, chunking, and sentence frame]
- L3–4: [specific partially structured academic frame]
- L5–6: [specific independent academic-language prompt]

ACCESSIBILITY:
- Use descriptive headings and a logical reading order.
- Use simple tables with clearly marked header rows.
- Do not rely on color alone.
- Provide sufficient contrast and writing space.
- Recommend alt text for necessary images.
- Write screen-reader-friendly directions.

BILINGUAL PARITY:
- Create equivalent English and Spanish student editions.
- Preserve the same assessed content, rigor, questions, and response opportunities.
- Do not shorten the Spanish edition.

REQUIRED OUTPUTS:
1. Editable English student worksheet
2. Equivalent editable Spanish student worksheet
3. Separate teacher answer key
4. Brief teacher implementation note
5. Source and citation list

CONTENT GUARDRAILS:
- Do not alter or paraphrase the provided standard.
- Do not replace the selected worksheet type, learning target, source set, or instructional focus.
- Do not invent quotations, dates, statistics, sources, documents, or image citations.
- Mark uncertain information [VERIFY].
- Do not copy proprietary commercial curriculum.
- Use HIPP for lesson-level source analysis; use HIPPO only for a complete DBQ.
- Preserve the historical-thinking demand across MTSS and WIDA supports.
- Do not include student data or personally identifiable information.
- Do not mention external curriculum marketplaces.
- Do not ask the teacher for more information. If a minor formatting choice is unspecified, choose the most accessible option and proceed.

EXPECTED UPLOAD FILENAME:
[US.xx - Descriptive Material Name - Student.docx]
```

## Prompt Quality Check

Before delivery, confirm:

- All brackets have been replaced.
- Standard wording is verbatim.
- SSP selection matches the student task.
- Worksheet type, target, focus, perspectives, and source/content set are all preselected.
- The execution directive prohibits follow-up questions.
- UDL options are actionable.
- MTSS tier and fading plan are explicit.
- WIDA supports are content-specific.
- Outputs and filename are unambiguous.
