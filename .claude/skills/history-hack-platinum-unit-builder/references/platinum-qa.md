# Platinum QA Checklist

## Critical Release Gates

- [ ] Current standards are accurate and complete.
- [ ] Standards match the verified source verbatim.
- [ ] Future standards are clearly labeled as a crosswalk, not current instruction.
- [ ] Every lesson activity maps to a standard and assessment.
- [ ] Every factual claim requiring verification has been checked.
- [ ] Primary sources have complete citations and rights classifications.
- [ ] No prohibited or unlicensed copied commercial materials are included.
- [ ] No missing, corrupt, placeholder, or manifest-only file is marked Included.
- [ ] Unit deck references and lesson-plan slide numbers match.
- [ ] Complete-unit ZIP includes all standards and the deck exactly once.
- [ ] 46-, 43-, and 41-minute schedules each total correctly.
- [ ] Exit ticket time remains protected in every schedule.

## Instructional Design

- [ ] Backward design is visible.
- [ ] Retrieval practice opens each lesson.
- [ ] New content is chunked and modeled.
- [ ] Guided practice precedes independent practice.
- [ ] At least two checks for understanding occur per lesson.
- [ ] Exit tickets measure the stated target.
- [ ] DOK progresses appropriately.
- [ ] Multiple perspectives and Tennessee connections appear where relevant.

## UDL and WIDA

- [ ] Engagement options are actionable.
- [ ] Representation options include language, visuals, vocabulary, and chunking.
- [ ] Action/expression options provide meaningful response choices.
- [ ] WIDA L1–2, L3–4, and L5–6 supports are present.
- [ ] Sentence frames match language demands.
- [ ] Supports do not lower the historical thinking target.
- [ ] Spanish materials are accurate and culturally/linguistically appropriate.
- [ ] Student-facing English and Spanish materials have content parity.
- [ ] Teacher-facing materials remain English unless a separate bilingual edition was commissioned.

## Accessibility

- [ ] WCAG 2.2 AA contrast.
- [ ] Official dark navy palette is used consistently.
- [ ] Heading hierarchy is correct.
- [ ] Tables have header rows.
- [ ] Images have useful alt text.
- [ ] Reading order is logical.
- [ ] Keyboard and focus states work in the generator.
- [ ] Documents are usable in grayscale and at 200% zoom where applicable.

## Files and Branding

- [ ] Editable Word original exists for every required document.
- [ ] Teacher lesson plans are landscape.
- [ ] PDF exports match Word originals.
- [ ] Official History Hack emblem is used.
- [ ] No invented HH mark.
- [ ] No marketplace/TpT language.
- [ ] No “master” terminology.
- [ ] No shortcuts.
- [ ] One authoritative source document per asset.
- [ ] TEAM-labeled content uses verbatim TDOE TEAM rubric language.
- [ ] Content-mastery criteria are not mislabeled as TEAM.

## Generator and ZIP

- [ ] Current-lesson ZIP name includes the selected standard.
- [ ] Complete-unit ZIP name clearly indicates the full unit.
- [ ] Student and teacher folders are separated.
- [ ] All expected files return HTTP 200 or equivalent.
- [ ] All DOCX files are unique.
- [ ] Deck appears once.
- [ ] README is present.
- [ ] Selected PDFs merge in the selected order.
- [ ] Progress, error, and success messages are accessible.
- [ ] Worksheet approval, visibility, version, and revision-date metadata are preserved.
- [ ] Automated tests, lint, type checks, and production build pass, except documented unrelated pre-existing failures.

## Final Reconciliation

Report exact counts:

- Standards
- Lessons
- DOCX
- PDF
- PPTX
- Student files
- Teacher files
- Generator-backed materials
- Missing files
- Duplicate files
- QA failures

A unit is not Platinum-ready while any critical release gate remains open.
