# Full Unit Production Workflow

## Phase A: Discovery and Salvage

1. Identify the current source repositories and storage locations.
2. Inventory the unit folder, Platinum-ready print folders, worksheet libraries, teacher materials, primary-source packets, assessment banks, exit tickets, starters, Cornell notes variants, Venn diagrams, compare/contrast organizers, and existing decks.
3. Hash or otherwise compare likely duplicates.
4. Build a salvage ledger with columns:
   - Asset
   - Current location
   - Standard(s)
   - Student/teacher
   - Format
   - Editable original present?
   - Quality
   - Rights/citation status
   - Decision
   - Destination
   - Required revision
5. Consolidate approved assets by moving them into the unit structure. Do not create shortcuts.
6. Preserve only one authoritative editable original.

## Phase B: Standards and Backward Design

1. Confirm current standards.
   - Read them from the verified standards source of truth.
   - Preserve official wording verbatim.
   - Never infer missing wording from a prior conversation.
2. Create a separate future-standards crosswalk if required.
3. Define transfer goals, essential questions, enduring understandings, and learning targets.
4. Design assessment evidence before daily activities.
5. Map each standard to deck slides, lesson days, sources, vocabulary, formative checks, and exit tickets.
6. Verify standards 1 through the final standard in the unit; never stop at an arbitrary partial range.
7. Build all three timing variants: 46-minute regular, 43-minute activities, and 41-minute late-start.
8. Protect the exit ticket in all three variants.
9. Use geography only where the SSP map calls for geographic reasoning.

## Phase C: Representative Standard

Before mass production, complete one representative standard:

1. Landscape teacher lesson plan
2. Student materials
3. Teacher editions/keys
4. Assessment and exit ticket
5. UDL/WIDA/accessibility supports
6. Generator connection
7. Current-lesson ZIP
8. Selected PDF package
9. English/Spanish parity for all student-facing materials

Present it for review when the user has requested review-first execution. Apply approved changes to the unit template.

## Phase D: Parallel Production

Split work into independent tracks:

- Standards and instructional sequence
- Primary sources and citations
- Student Word files
- Teacher Word files and keys
- Assessment and exit tickets
- Unit deck
- UDL/WIDA/accessibility
- Generator integration
- Fact-check/copyright QA

One worker owns each authoritative file at a time. Use a shared manifest to prevent naming collisions and duplicate creation.

## Phase E: File Generation

1. Build editable DOCX first.
2. Validate headings, tables, margins, orientation, page breaks, accessibility, and branding.
3. Export each approved DOCX to PDF.
4. Compare PDF pagination and content to the Word original.
5. Record the physical path, public app path, file size, checksum if used, standard, audience, and category in the manifest.
6. Record approval state, student-visible state, version, and revision date for worksheet-governed assets.

## Phase F: Deck

1. Build or correct one complete unit deck.
2. Map lesson plan references to actual slide content.
3. Inspect every standard divider, source, activity, check, and closure slide.
4. Confirm deck title, standard labels, citations, notes, emblem, and brand colors.
5. Store and download the deck once.

## Phase G: Generator

1. Add the unit and standards to the generator data model.
2. Add only real, accessible files.
3. Test one-standard selection.
4. Test all-standard selection.
5. Test current-lesson DOCX ZIP.
6. Test complete-unit DOCX ZIP.
7. Test merged PDF package.
8. Test deck download.
9. Test desktop, mobile, keyboard, and screen-reader semantics.
10. Keep the PR draft until review.

## Phase H: Final Release

1. Reconcile manifest against disk.
2. Validate all file types open.
3. Run Platinum QA.
4. Generate README and unit inventory.
5. Create district folder/ZIP.
6. Provide preview and completion report.
7. Move to live shared Drive or merge only after approval.
