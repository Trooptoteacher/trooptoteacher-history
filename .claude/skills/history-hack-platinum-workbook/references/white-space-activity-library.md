# White-Space Activity Library

This is the locked Unit 4 Platinum-standard library for converting accidental workbook white space into meaningful student learning without creating spill pages. Read this file during every DBQ build and every sparse-page remediation pass.

## Core rule

Measure unused area inside the printable body after rendering, excluding running headers, footers, and margins.

| Unused printable body | Required disposition |
|---|---|
| Under 20% | Pass |
| 20–40% | Quarter-page activity |
| 40–65% | Half-page activity |
| 65–80% | Three-quarter-page activity |
| Over 80% | Merge/reflow first; use a full-page lab only if the page is necessary |

Intentional labeled writing, drawing, mapping, graphing, planning, or note-taking space is exempt. Unlabeled emptiness, orphaned prompts, detached options, and carryover fragments are defects.

## Selection rules

1. Match the activity to the page's content, standard, source type, and DBQ prompt.
2. Produce observable student thinking: writing, sorting, graphing, mapping, speaking preparation, sourcing, corroboration, or argument construction.
3. Preserve scaffold fading:
   - `early`: explicit sequence, optional word bank, model, or sentence frame;
   - `middle`: reduced cues, optional stem, comparison, or student choice;
   - `late`: independent analysis, self-monitoring, counterclaim, or evidence selection.
4. Never add filler prose, decorative images, repeated comprehension questions, or busywork.
5. Never let the activity create another page. If it cannot fit, select a smaller component or reflow.
6. Essential instructional text is 10.5pt when practical and never below 9.5pt. Source credits and footers are not part of the activity.

## Quarter-page activities

Use for 20–40% unused space. Target one compact thinking move with 2–4 response lines.

### Evidence to inference to significance
- Evidence: quote or describe one specific detail.
- Inference: explain what the detail suggests.
- Significance: explain why it matters to the DBQ.

### Corroboration exit ticket
- Name one document that agrees or disagrees.
- Explain the connection in one sentence.

### Sourcing quick check
- Identify creator, audience, or purpose.
- Explain how that feature affects usefulness or reliability.

### One-sentence data claim
- State the trend.
- Include one number.
- Connect it to one document or historical development.

### Counterclaim check
- State the strongest reasonable opposing claim.
- Name one document that supports it.

### Vocabulary or cognate connection
- Define one essential term in student-friendly language.
- Use it accurately in a claim.
- For multilingual access, identify a useful cognate without replacing English-language development.

### Confidence check and next action
- Select: ready, almost ready, or need support.
- Name the next action: reread, use the companion, compare a source, ask a partner, or revise the claim.

### Best-evidence selection
- Choose the strongest detail on the page.
- Explain why it is stronger than another available detail.

## Half-page activities

Use for 40–65% unused space. Target a multi-step analysis with visible student choice or synthesis.

### Compare and corroborate matrix
Columns: Source A, Source B, agreement, disagreement, and which is more useful for the DBQ.

### Claim-evidence-reasoning builder
- Draft one defensible claim.
- Add two source details.
- Explain how each detail supports the claim.

### Evidence route planner
- Select one source from each document cluster.
- Predict which side of the DBQ it supports.
- Record why it may be useful.

### Thesis stress test
- Draft a thesis.
- Test it against one contradictory document.
- Revise the thesis to account for complexity.

### Student choice processing lab
Choose one, not all:
- 15-word headline;
- labeled evidence sketch;
- partner paraphrase notes;
- claim-evidence link;
- cause-and-effect chain.

### Context ladder
Move from event detail to unit development to broader national context, then connect the context to the source.

### Data transformation task
Sketch the trend from a table, label the turning point, write a data claim, and connect it to a document.

## Three-quarter-page activities

Use for 65–80% unused space. Target a substantial lab that can stand as a complete learning experience.

### Source investigation lab
Sequence: identify, explain, contextualize, corroborate, and build a claim. Add a processing choice and a short exit ticket when space permits.

### Cluster synthesis lab
- Sort sources into two or more interpretations.
- Rank the strongest evidence on each side.
- Identify a contradiction or limitation.
- Write a provisional thesis.

### Data and map reasoning lab
- Read title, scale, legend, categories, and geography.
- Transform or annotate the data.
- Identify a pattern.
- Explain one historical cause and one consequence.
- Connect the finding to the DBQ.

### Mini-DBQ challenge
- Analyze two or three short sources.
- Source or contextualize at least one.
- Corroborate across sources.
- Write a short claim-evidence-reasoning response.

### Tennessee connection investigation
- Examine a Tennessee primary source, map, statistic, or local case.
- Connect the state example to the national development.
- Explain whether Tennessee confirms, complicates, or challenges the broader pattern.

### Historical decision lab
- Identify the historical problem and stakeholder options.
- Evaluate evidence available at the time.
- Select and defend a decision.
- Compare the decision with the historical outcome.

## Full-page lab after reflow failure

Use only when more than 80% of a necessary page remains unused after a documented merge/reflow attempt. Choose a three-quarter activity and expand response space, evidence tables, graphing area, or a structured reflection. Do not manufacture a new reading passage merely to fill the page.

## Context matching

| Page type | Preferred activities |
|---|---|
| Document roster or overview | Evidence route planner, cluster prediction |
| Text primary source | Sourcing quick check, CER builder, compare/corroborate, source investigation |
| Visual primary source | Evidence sketch, OPTIC extension, inference chain, independent source analysis |
| Data table or chart | One-sentence data claim, data transformation, data reasoning lab |
| Map | Map reasoning lab, geographic inference, Tennessee connection |
| Prewriting or essay planning | Thesis stress test, counterclaim check, evidence route planner |
| Vocabulary or language access | Cognate connection, student self-use checklist, sentence-frame choice |
| Teacher guide | Decision rules, implementation notes, scoring calibration; never student busywork |

## QC log schema

For every page at or above 20% unused, record:

`page | unused_pct | band | original_issue | disposition | activity | context | scaffold_stage | min_instructional_font | page_count_before_after | visual_pass`

No workbook is Platinum-ready until every flagged page has a defensible disposition and no activity creates a spill page.
