# Schedule F Self-Score

Instrument: **TDOE High School Social Studies Instructional Materials Scoring Rubric** (Schedule F / TN Textbook and Instructional Materials Quality Commission).
Rubric PDF: https://www.tn.gov/content/dam/tn/textbook-commission/documents/schedule-f/High_School_Social_Studies_Rubric.pdf

## Scale
- 0 — not present. 1 — present but intent/frequency not fully met. 2 — present and fully met.

## Structure
- **Gateway / Table 1 — Alignment:** a TN standards alignment guide present + all unit standards addressed. MET when the crosswalk is bound into the workbook, listed in the TOC, with independently verified page references. Honestly mark any Context standards.
- **Table 2 — Instructional Focus** (9 indicators, max 18): Essential Q, Supporting Q, Student-Centered, Disciplinary Literacy, Multiple Perspectives, Concepts-before-Vocabulary, Connections across content, Connects across disciplines, Review Opportunities.
- **Table 3 — Social Studies Practices / SSPs** (7 indicators, max 14): collect, critically examine, synthesize, construct+communicate, historical awareness, geographic awareness (SSP.06), focus-SSP support.
- **Table 4 — Accessibility** (2 indicators, max 4): all lessons digital + printable; SWD + EL supports in every lesson.
- **Total = Tables 2-4, max 36.** Statutory bar: ≥80% on the rubric AND Gateway satisfied.

## Honesty doctrine (this is what makes the card defensible)
- Score the package **as built**, never as planned. Every note states the evidence and any gap plainly.
- **Hold indicators low on principle when appropriate.** Example from Unit 1: "Review Opportunities" is held at **1 by design** because spaced review is a curriculum-layer responsibility (teacher sequencing against lecture decks / TCAP hub / other units), not something a single standalone DBQ should carry. A documented, principled non-claim beats an inflated 2. State the intended ceiling explicitly (Unit 1 ceiling = 34/36 = 94%).
- Mark contextual standards **Context**, not Full, with a footnote.
- History Hack is **supplemental** under T.C.A. §49-6-2202(a)(3) — no Commission approval required; the self-score is a defensibility artifact, disclosed as a publisher self-assessment.
- Author/producer = **TroopToTeacher Technologies LLC**; disclose Perplexity Computer only as a drafting tool.
- Common Core RH/WHST codes are cited internally as cross-subject proof ONLY — never marketed as Common Core-aligned (T.C.A. §49-6-2202).
